## Legend FCCD Analysis
This repository contains the scripts used to determine the FCCD and Active Volume (AV) of the LEGEND ICPC germanium detectors characterized in HADES.
This repository is an adjustment of [link text](https://github.com/abialexander/legend-AV-analysis).

The data used in this analysis is the HADES characterisation data, stored in <code>/global/cfs/cdirs/m2676/users/biancacci/hades-proc/legend-dataflow-hades/generated/tier/hit </code>.
It needs <code>pygama-v0.9.0</code>.
The MC simulations used are generated by <code> legend-g4-simple-simulation </code>, which automatically generates raw MC spectra and AV postprocessing, according to a given config file.

### Analysis Flow
The master script <code>Process_Detectors.py</code> allows automatic and rapid processing of each detector.
 However the following order must be followed.
 1) Gamma line counting of calibrated data <code> (python3 Process_Detectors.py --data config.json) </code>
 2) Generate raw MC & perform AV post processing for range of FCCDs (use  <code> legend-g4-simple-simulation </code>)
 3) Gamma line counting of each AV post processed MC <code> (python3 Process_Detectors.py --sim config.json) </code>
 4) Compute best fit FCCD <code> (python3 Process_Detectors.py --fccd config.json) </code>
 5) Compute Active Volume <code> (python3 Process_Detectors.py --av config.json) </code>
 
 Optional:
 6) AV postprocessing for best fit FCCD
 7) Gamma line counting for MC with best fit FCCD
 8) Plot comparison spectra of data with best fit FCCD

 ### Detectors comparison
The script <code>Compare_Detectors.py</code> combine all FCCDs, Active Volumes, and Active volume fractions for every analyzed measurements of all detectors in a single JSON file, and generates a summary plot showing all FCCDs of all detectors.
